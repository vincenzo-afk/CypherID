# Camera Resistance Demo

## Setup
- Display laptop connected to external monitor at 60 Hz
- Phone camera (standard, 30fps auto exposure)
- Demo content: single page of text (classified document sample)

## Demo Steps

1. **Baseline — no protection**
   - Show unprotected text on screen
   - Photograph with phone
   - Show clear, readable photograph

2. **LOW profile**
   - Enable LOW protection
   - Photograph with phone
   - Show: text still mostly readable, watermark visible

3. **HIGH profile**
   - Enable HIGH protection
   - Photograph with phone
   - Show: text partially distorted, watermark visible
   - Show OCR attempt on captured image (reduced accuracy)

4. **EXTREME profile**
   - Enable EXTREME protection
   - Photograph with phone
   - Show: text significantly distorted
   - Note: human on screen can still read

## Honest Presentation
State explicitly during demo:
- "This is camera-resistant rendering — it makes capture harder, not impossible."
- "The watermark remains visible in all captures — allowing us to identify the session."
- "OS-level screen recording is not prevented — but is monitored for browser-observable events."
