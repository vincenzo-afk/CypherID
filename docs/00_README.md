# CypherID — Documentation Root

## What is CypherID?

CypherID is a permissioned blockchain platform built on Hyperledger Fabric (Java chaincode) and Spring Boot that replaces centralized IAM with a decentralized, cryptographically verifiable, and tamper-proof identity and asset management system, extended with a Camera-Resistant Protected Content subsystem.
