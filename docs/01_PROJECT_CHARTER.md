# Project Charter

## Project Name
CypherID — Blockchain-Based Secure Platform for Identity, Access Control, and Digital Asset Management

## Problem Statement Number
SIH26125

## Organization
Bharat Electronics Limited (BEL)

## Theme
Blockchain & Cybersecurity

## Tagline
"Your Identity. Your Control. Immutable Trust."

## Sponsoring Organization
Smart India Hackathon (SIH)

## Core Objectives
1. Self-Sovereign Identity (SSI) via Decentralized Identifiers (DIDs)
2. Smart Access Control — RBAC + ABAC enforced on-chain with immutable audit trails
3. Digital Asset Vault — tokenized ownership with encrypted off-chain storage
4. Zero-Trust Security — cryptographic verification for every access request
5. Camera-Resistant Protected Content — software-based content protection layer

## Primary Language
Java 21 (LTS) — 80%+ of codebase

## Secondary Languages
JavaScript/TypeScript (React frontend only)

## Team Roles
- Team Lead / Architect
- Blockchain Developer (Java chaincode)
- Backend Lead (Spring Boot)
- Frontend Developer (React)
- Security Engineer
- DevOps

## Success Criteria
- Live demo: register DID, upload asset, request access (denied + approved), audit trail visible
- All chaincode transactions verifiable with real tx hashes
- Protected content subsystem integrated and demonstrable
- Fully dockerized, runs on a laptop
