# Access Denial Reasons

| Reason Code | Description |
|:---|:---|
| INSUFFICIENT_CLEARANCE | No matching VC/role |
| ABAC_MISMATCH | Attributes don't match policy |
| DID_INACTIVE | DID suspended or revoked |
| TIME_RESTRICTION | Outside allowed hours |
| POLICY_NOT_FOUND | No policy for resource |
| MULTI_SIG_PENDING | Awaiting approvals |
