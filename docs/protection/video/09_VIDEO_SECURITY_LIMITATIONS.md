# Video Security Limitations

## Cannot Be Prevented
1. Screen recording via OS tools
2. Physical camera recording of display
3. HDMI capture devices

## Provided By This System
1. Server-side authorization before any content delivery
2. Expiring playback sessions
3. Dynamic watermarking for forensic traceability
4. Browser-observable event monitoring
5. Anti-download controls (deterrence layer)
6. Camera-resistant rendering on video canvas

## Correct Statement
"Protected video playback with authenticated access, expiring sessions, dynamic watermarking, and browser-side capture monitoring. OS-level screen recording cannot be prevented by browser-based technology."
