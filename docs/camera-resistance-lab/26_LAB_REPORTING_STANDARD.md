# Lab Reporting Standard

Every lab report must include:
1. Test environment (display, camera, browser, OS, date)
2. Test methodology reference (02_RESEARCH_METHODOLOGY.md)
3. Baseline result
4. All configuration results (not cherry-picked)
5. Statistical measures (mean, SD, CI)
6. Limitations section
7. Claims supported by results
8. Claims NOT supported by results

Fabricating results is prohibited. Omitting unfavorable results is prohibited.
