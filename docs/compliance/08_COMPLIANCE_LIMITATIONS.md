# Compliance Limitations

## Not a Certified System
CypherID is a prototype for hackathon demonstration.
It has NOT undergone:
- Formal security accreditation
- Penetration testing by accredited testers
- FIPS 140-2 certification for cryptographic modules
- Common Criteria evaluation

## Camera Resistance Not Certified
Camera-resistant rendering is experimental.
Effectiveness claims are based on lab testing, not certified evaluation.

## For Production Use
Before deploying in a classified defense environment:
- Full security assessment and penetration test required
- Formal key management procedures required
- HSM for all cryptographic key storage required
- Network air-gap design required
- Regulatory compliance review required
