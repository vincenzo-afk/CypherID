# Responsive Behavior

## Breakpoints
- Mobile: < 768px
- Tablet: 768px – 1024px
- Desktop: > 1024px

## Mobile Support
Admin panel: desktop only (complex tables).
Protected viewers: desktop/tablet (keyboard needed for exams).
Wallet and Asset Hub: responsive (mobile usable).

## Protected Viewer on Mobile
Protected document viewer: single-column layout, swipe for pages.
Exam viewer: not supported on mobile (keyboard required for answers).
