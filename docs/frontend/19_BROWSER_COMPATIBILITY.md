# Browser Compatibility

## Supported Browsers
| Browser | Min Version | Protected Renderer |
|:---|:---|:---|
| Chrome | 90+ | Full (Canvas + WebGL) |
| Firefox | 88+ | Full (Canvas + WebGL) |
| Edge | 90+ | Full (Canvas + WebGL) |
| Safari | 15+ | Canvas only (WebGL limited) |
| Mobile Chrome | 90+ | Canvas only |
| Mobile Safari | 15+ | Canvas only (reduced effects) |

## Unsupported
- Internet Explorer: not supported
- Opera Mini: not supported

## Degradation
Canvas unavailable → CSS protection only + admin notified.
WebGL unavailable → Canvas 2D fallback (no degradation in core functionality).
