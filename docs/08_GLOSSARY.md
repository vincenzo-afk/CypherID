# Glossary

| Term | Definition |
|:---|:---|
| DID | Decentralized Identifier — a W3C-standard globally unique identifier controlled by the subject |
| DID Document | A JSON document containing public keys, authentication methods, and service endpoints for a DID |
| VC | Verifiable Credential — a W3C-standard digitally signed credential issued by an authorized organization |
| RBAC | Role-Based Access Control — access decisions based on assigned roles |
| ABAC | Attribute-Based Access Control — access decisions based on contextual attributes |
| Fabric | Hyperledger Fabric — a permissioned enterprise blockchain platform |
| Chaincode | Smart contract code running on Hyperledger Fabric peers |
| Peer | A Fabric network node that maintains the ledger and executes chaincode |
| Orderer | A Fabric node responsible for transaction ordering and block creation |
| Channel | A private Fabric subnet with its own ledger |
| World State | The current state database for a Fabric channel (CouchDB in this system) |
| IPFS | InterPlanetary File System — a distributed file storage protocol |
| AES-256-GCM | Advanced Encryption Standard with 256-bit key in Galois/Counter Mode |
| NFT | Non-Fungible Token — a unique on-chain record representing ownership of an asset |
| SSI | Self-Sovereign Identity — identity model where users control their own credentials |
| ZKP | Zero-Knowledge Proof — a cryptographic method to prove knowledge without revealing it |
| Camera-Resistant | A rendering technique designed to reduce camera readability while maintaining human readability |
| Temporal Modulation | Varying display content over time to interfere with camera frame capture |
| Spatial Dithering | Adding spatially varying visual patterns to reduce OCR and camera readability |
| Rolling Shutter | A camera sensor capture mode that reads rows sequentially, enabling interference techniques |
| Protection Profile | A named configuration (LOW/MEDIUM/HIGH/EXTREME) for protection parameters |
| Protected Session | An authorized, time-limited session for viewing protected content |
| Watermark | An embedded identifier in displayed content for forensic traceability |
| Isolation Forest | An unsupervised ML algorithm for anomaly detection |
| Kafka | Apache Kafka — a distributed event streaming platform |
| HSM | Hardware Security Module — dedicated hardware for cryptographic key management |
| Shamir's Secret Sharing | A cryptographic method to split a secret into N shares, requiring K shares to reconstruct |
