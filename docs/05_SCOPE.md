# Scope

## In Scope

### Blockchain IAM
- Hyperledger Fabric network (3 orgs, 2 peers each, orderer)
- Java chaincode: Identity, AccessControl, AssetRegistry
- DID creation, resolution, suspension, revocation
- Verifiable Credential issuance and verification
- RBAC + ABAC policy engine on-chain
- Multi-signature approval for classified resources
- Time-bound and delegated access
- Digital asset minting, transfer, burn
- Encrypted IPFS storage with AES-256-GCM
- Immutable audit trail
- PDF audit report generation

### Spring Boot Backend
- API Gateway (Spring Cloud Gateway)
- Identity Service, Access Service, Asset Service, Audit Service
- Protection Policy Service, Protected Session Service, Watermark Service
- Protected Content Service, Security Event Service
- Kafka event streaming, Redis caching, PostgreSQL persistence

### Camera-Resistant Protection
- Camera-resistance rendering engine (HTML/Canvas/WebGL)
- Temporal modulation, spatial dithering, dynamic patterns
- Session-specific watermarking
- Protected document, exam, and video modes
- Browser-side capture monitoring (observable events only)
- Protection state machine
- LOW / MEDIUM / HIGH / EXTREME protection profiles
- Camera Resistance Lab (research benchmark module)

### Frontend
- React 18 + Material-UI
- Login, Identity Wallet, Asset Hub, Access Requests, Admin Panel
- Audit Dashboard, Protected Document UI, Protected Exam UI, Protected Video UI

### AI
- Python FastAPI anomaly detection microservice
- Isolation Forest model
- Kafka consumer pipeline
