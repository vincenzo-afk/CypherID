# AI Model Directory

The Isolation Forest model lives here as `isolation_forest.pkl`.

The AI service NEVER fabricates training data. The model must be trained
offline on REAL access-log data before the service can start:

    # From a Kafka replay of the access-logs topic
    python train.py --kafka-bootstrap localhost:9092 --topic access-logs \
                    --output model/isolation_forest.pkl

    # Or from an exported JSONL file of real access events
    python train.py --input access_events.jsonl --output model/isolation_forest.pkl

Without a trained model, the service refuses to start with an actionable
error instead of inventing one (no synthetic data, per project policy).

The file is generated by training; it is not committed.
